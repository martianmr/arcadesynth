# arcadesynth 0.0.5

Programmatically synthesize retro arcade sound effects with arcadesynth

This utility can be used to generate custom sound effects without importing sound assets, sounds from some classic arcade games of the 70s and 80s are included.

## Modules

From python use help(module) to get more information:

- synth - functions to build your own effects
- synth_sample - some simple basic sounds
- synth_example - some generic retro sound effects
- synth_asteroids - sounds from the 1979 Atari game Asteroids
- synth_spaceinvaders - sounds from the 1978 Taito game Asteroids
